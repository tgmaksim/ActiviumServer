Содержание документа

Что входит в отчёт

PDF содержит компактные таблицы с учебными результатами выбранного класса:

  • имена учащихся;
  • предметы и оценки по каждому ученику;
  • средний балл;
  • рейтинг в представлении приложения {{ project_name }}.

Это сводный документ с оценками, а не самостоятельное педагогическое заключение: он помогает быстро просмотреть собранные данные и подготовить их к печати.

Источник информации

Данные электронного журнала

Для формирования отчёта используется авторизация через «Дневник.ру». Класс выбирается из списка, доступного вошедшему учителю, а оценки берутся из доступных учебных данных этого класса. Это избавляет от необходимости вручную собирать оценки по отдельным страницам журнала и переносить их в документ.

Частые вопросы

О помощнике учителю

Какие данные будут в PDF?

В документе представлены имена учащихся, предметы, оценки, средний балл и рейтинг в том виде, в каком он отображается пользователям {{ project_name }}.

Откуда берутся оценки?

Помощник работает с учебными данными «Дневника.ру», доступными авторизованному учителю для выбранного класса.

Как формируется рейтинг в классе?

Общий рейтинг по классу учитывает средние баллы по всем предметам с оценками и считает между ними новое среднее — это и будет значение ученика в рейтинге. Далее формируется список, отсортированный и пронумерованный на основе получившегося балла.

Можно ли распечатать отчёт?

Да. Отчёт формируется в формате PDF, поэтому его можно просмотреть, сохранить и распечатать.

Заменяет ли отчёт электронный журнал?

Нет. Это компактная сводка оценок для просмотра и печати. Для работы с электронным журналом и исходными данными по-прежнему используется «Дневник.ру».
