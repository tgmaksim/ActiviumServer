1. Общие положения

Настоящая Политика конфиденциальности описывает, какие данные обрабатываются при использовании сервиса {{ project_name }}, для каких целей они используются, где хранятся и каким образом пользователь может обратиться по вопросам их обработки.

Политика распространяется на все версии {{ project_name }}, включая приложение для Android и веб-приложение (PWA), а также связанные с ними серверные компоненты. Она применяется независимо от версии клиента, установленной пользователем.

{{ project_name }} — независимый информационный сервис, предоставляющий дополнительные возможности для работы с учебной информацией, получаемой из «Дневника.ру».

Обработка данных осуществляется в объёме, необходимом для предоставления функций сервиса, обеспечения его работоспособности и безопасности, диагностики ошибок и улучшения качества {{ project_name }}.

2. Какие данные обрабатываются

2.1. Данные профиля

Для работы с профилем {{ project_name }} получает из «Дневника.ру» имя пользователя и первую букву его фамилии. Полную фамилию пользователя {{ project_name }} не запрашивает и не сохраняет.

В зависимости от используемых функций сервис также может получать имя и первую букву фамилии связанных с пользователем лиц, например: одноклассников, детей или родителей. Эти сведения предоставляются «Дневником.ру» в рамках авторизованного взаимодействия.

2.2. Данные из «Дневника.ру»

Для получения учебной информации пользователь проходит авторизацию через «Дневник.ру». После авторизации {{ project_name }} получает токен доступа, позволяющий взаимодействовать с «Дневником.ру» от имени пользователя.

Токен используется для выполнения запросов, необходимых для работы функций {{ project_name }}. Срок его действия определяется правилами «Дневника.ру» и обычно составляет около 30 дней. После истечения срока действия токен перестаёт работать, и пользователю требуется повторная авторизация.

В процессе работы сервис получает и обрабатывает учебные сведения, доступные соответствующему аккаунту в «Дневнике.ру». В зависимости от прав пользователя к ним могут относиться расписание, оценки, домашние задания и другие учебные сведения, необходимые для работы функций {{ project_name }}.

После истечения срока действия токена некоторые учебные данные могут продолжать храниться на сервере {{ project_name }}. Они не удаляются автоматически только по причине истечения срока действия токена. Полные фамилии пользователей из «Дневника.ру» {{ project_name }} не сохраняет.

2.3. Отзывы

Пользователь может оставить отзыв о сервисе. После прохождения модерации отзыв может быть опубликован на сайте {{ project_name }}. В опубликованном отзыве может отображаться имя и первая буква фамилии его автора.

Пользователь может самостоятельно удалить свой отзыв без дополнительного подтверждения. Для управления отзывом необходимо войти в {{ project_name }} через «Дневник.ру».

2.4. Технические журналы сервера

Для обеспечения работоспособности, диагностики ошибок и защиты сервиса сервер сохраняет журналы взаимодействия. Запись журнала может содержать:

  • IP-адрес;
  • идентификатор пользовательской сессии (sessionId);
  • путь запроса;
  • результат выполнения запроса или сведения об ошибке, например код и статус ответа либо текст ошибки;
  • время создания записи.

В отдельных случаях текст ошибки может содержать имя пользователя, если оно присутствует в сообщении об ошибке. {{ project_name }} не сохраняет в этих журналах полное содержимое ответов сервера с учебной информацией, расписанием, домашними заданиями и сведениями об одноклассниках.

Журналы используются для обнаружения и исправления ошибок, анализа сбоев и обеспечения безопасности. Автоматическое удаление таких записей по установленному сроку не предусмотрено.

2.5. Идентификаторы push-уведомлений

Для доставки push-уведомлений {{ project_name }} использует Firebase Cloud Messaging. Для этого клиент получает Firebase Installation ID (FID), который сохраняется на сервере и связывается с пользовательской сессией.

FID является техническим идентификатором установки приложения и используется для доставки уведомлений. Сам по себе он не содержит имени, фамилии или учебной информации пользователя.

Текст уведомлений может содержать имя и первую букву фамилии пользователя или связанного с ним лица, текст похвалы, полученную оценку и другие сведения, необходимые для отображения соответствующего события.

2.6. Данные аналитики и диагностики

Клиенты {{ project_name }} используют Firebase Analytics и Firebase Crashlytics для сбора статистики использования и диагностики ошибок. В зависимости от настроек и используемых компонентов Firebase могут обрабатываться:

  • модель устройства и версия операционной системы;
  • версия приложения;
  • сведения о запусках, сессиях и взаимодействии с приложением;
  • технические идентификаторы установки;
  • приблизительная страна или регион, определяемые по IP-адресу;
  • сведения о сбоях, исключениях и технические данные, необходимые для диагностики.

В отчёты Crashlytics передаются технические сведения об ошибках. В используемой конфигурации {{ project_name }} пользовательские данные и содержимое учебной информации намеренно в такие отчёты не добавляются.

Сбор аналитики и диагностики осуществляется с использованием инфраструктуры Firebase в соответствии с документацией и условиями соответствующих сервисов Google.

3. Цели обработки данных

Данные обрабатываются для следующих целей:

  • авторизация пользователя и поддержание пользовательской сессии;
  • получение и отображение учебной информации из «Дневника.ру»;
  • предоставление функций {{ project_name }} с учётом прав пользователя в «Дневнике.ру»;
  • доставка push-уведомлений;
  • публикация и управление отзывами;
  • обеспечение безопасности и работоспособности сервиса;
  • обнаружение, анализ и исправление технических ошибок;
  • сбор статистики использования и улучшение сервиса.

4. Хранение данных

Данные, необходимые для работы {{ project_name }}, хранятся в базе данных на инфраструктуре хостинг-провайдера NetAngels. На инфраструктуре этого провайдера также размещены серверная часть и веб-приложение. Серверы {{ project_name }} размещаются на территории Российской Федерации.

Учебные сведения и другие данные, сохранённые на сервере, не удаляются автоматически по причине истечения срока действия токена «Дневника.ру». Удаление таких данных производится по обращению пользователя в поддержку {{ project_name }}.

Хостинг-провайдер может создавать резервные копии инфраструктуры, включая данные базы данных. Такие копии доступны разработчику через учётную запись хостинга и хранятся не более одного месяца. Условия хранения и резервного копирования со стороны провайдера определяются его собственными правилами.

Технические журналы сервера хранятся без установленного срока автоматического удаления.

5. Сторонние сервисы

Для работы {{ project_name }} используются следующие сторонние сервисы:

  • «Дневник.ру» — источник учебной информации и система авторизации. Взаимодействие осуществляется с использованием токена доступа, предоставленного после авторизации пользователя.
  • NetAngels — хостинг-провайдер, на инфраструктуре которого размещены сервер {{ project_name }}, база данных и веб-приложение.
  • Firebase (Google) — используется для аналитики, доставки push-уведомлений и диагностики сбоев.

Указанные организации могут обрабатывать технические данные в рамках предоставления своих услуг и в соответствии со своими условиями и политиками конфиденциальности. {{ project_name }} не продаёт пользовательские данные.

6. Реклама

В приложении для Android и веб-приложении {{ project_name }} могут отображаться рекламные материалы. На момент публикации настоящей редакции используются собственные рекламные материалы проекта.

Реклама размещается в небольшом формате и предназначена для поддержки развития сервиса. Если в будущем будут подключены сторонние рекламные платформы, сведения об этом и об их обработке данных будут отражены в Политике.

7. Разрешения и возможности устройства

Клиенты {{ project_name }} используют доступ к сети Интернет для взаимодействия с сервером. Приложения также могут запрашивать разрешение на отправку уведомлений.

В веб-приложении может выполняться локальная проверка наличия веб-приложения {{ project_name }} среди приложений, доступных браузеру для соответствующей проверки. Список установленных приложений не отправляется на сервер {{ project_name }} и не используется для составления перечня приложений на устройстве.

8. Защита данных

Для защиты данных применяются организационные и технические меры, включая:

  • использование HTTPS для взаимодействия клиентов с сервером;
  • ограничение доступа к API с помощью API-ключей и идентификаторов пользовательских сессий;
  • разграничение доступных операций в зависимости от типа сессии;
  • ограничение доступа к инфраструктуре сервера и использование защищённых учётных данных.

Доступ к отдельным функциям и данным может различаться в зависимости от способа авторизации. В частности, веб-сессия имеет ограничения по сравнению с сессией Android-клиента.

Несмотря на принимаемые меры, невозможно гарантировать абсолютную защиту информации от всех возможных угроз, включая компрометацию инфраструктуры или несанкционированный доступ третьих лиц.

9. Обращения и удаление данных

Пользователь может обратиться в поддержку {{ project_name }} по вопросам обработки относящихся к нему данных, в том числе чтобы получить информацию об обрабатываемых данных, запросить исправление данных, которые {{ project_name }} может изменить, или запросить удаление отдельных сведений либо всей информации, относящейся к пользователю.

Самостоятельное удаление аккаунта в интерфейсе {{ project_name }} не предусмотрено. Для удаления аккаунта и связанных с ним данных необходимо обратиться в поддержку. Запрос рассматривается с учётом технических возможностей сервиса и применимых требований законодательства.

Отзывы пользователь может удалять самостоятельно после входа в {{ project_name }}.

Изменение учебных сведений, полученных из «Дневника.ру», выполняется в самой системе «Дневник.ру». {{ project_name }} не является первоисточником таких сведений и не изменяет их в «Дневнике.ру».

10. Несовершеннолетние пользователи

{{ project_name }} может использоваться несовершеннолетними пользователями, в том числе учащимися школ, а также их родителями и законными представителями.

Доступные функции и сведения определяются правами соответствующего аккаунта в «Дневнике.ру». При использовании сервиса несовершеннолетними пользователями должны соблюдаться требования применимого законодательства и правила соответствующих сторонних сервисов.

11. Изменение Политики конфиденциальности

Разработчик {{ project_name }} вправе вносить изменения в настоящую Политику. Актуальная редакция всегда доступна на этой странице, а дата последнего обновления указывается в начале документа. Пользователю рекомендуется периодически знакомиться с актуальной редакцией Политики.

12. Контакты

По вопросам обработки данных, их исправления или удаления можно обратиться в поддержку {{ project_name }}.
